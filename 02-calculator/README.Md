# 🧮 Simple Web Calculator

A sleek, responsive, and lightweight calculator built using pure HTML, CSS, and JavaScript. It features a modern dark-themed UI and supports basic arithmetic operations.

## ✨ Features
*   **Basic Arithmetic:** Supports addition (`+`), subtraction (`-`), multiplication (`*`), division (`/`), and percentage (`%`).
*   **Clear & Delete:** Includes a Clear (`C`) button to reset the display and a Delete Entry (`DE`) button to remove the last character.
*   **Modern Design:** Built with a dark glassmorphic look using modern **CSS Grid** styling.
*   **Fully Responsive:** Scales beautifully across mobile, tablet, and desktop screens.
*   **Smooth Animations:** Includes tactile button press scaling and hover states.

## 📁 Project Structure
The project is organized into three single-purpose files:
```text
Calculator/
│
├── calculator.html   # Main layout structure
├── calculator.css    # Layout design, alignment, and colors
├── calculator.js    # Computational logic and math evaluation
└── README.md    # Project documentation
```

## 🚀 How to Run the Project
1.  **Clone or Download** this repository to your local machine.
2.  Ensure all three project files (`index.html`, `style.css`, and `script.js`) are kept inside the **same directory folder**.
3.  Double-click the `index.html` file to open and run the application instantly in your default web browser.
