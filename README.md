# 🚀 HTML • CSS • JavaScript Mini Projects

Welcome to my collection of **HTML, CSS, and JavaScript Mini Projects**.

This repository contains beginner to intermediate projects that I built to improve my frontend development skills. Each project focuses on solving a real-world problem while strengthening my understanding of JavaScript, DOM manipulation, responsive design, asynchronous programming, and browser APIs.

The goal of this repository is to practice consistently, improve problem-solving skills, and build a strong portfolio for frontend developer interviews.

# 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/html-css-js-mini-projects.git
```

2. Open the project folder.

3. Choose any project.

4. Open the `index.html` file in your browser.

Or use the VS Code **Live Server** extension for a better development experience.
